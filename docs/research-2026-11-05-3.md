# 第3回の検証レポート（「今」を重く見る方法）

> 過去の成績は、将来の成績を約束するものではありません。

設定は毎月見直す。その時点より前のデータだけで決める。金額は1回の許容損失2,500円で計算。
確認期間：2021年3月〜2026年4月。最新6か月：2026年5月〜11月。

## 分かったこと

1. **直近1か月だけで調整するのは悪い**。値動きのぶれに振り回され、ほとんどのルールで成績が下がった
2. **直近3か月で毎月見直す**のは、いくつかのルールで良かった
   - 一目均衡表＋損切り幅の下限＋日足の流れ：確認 ＋10.2万円（前半 ±0、後半 ＋10.2万円）、最新6か月 ＋4.4万円（47回）
   - ボリンジャーバンド＋日足の流れ：確認 ＋8.7万円、最新6か月 ＋3.1万円（44回）
   - 押し目・戻り＋日足の流れ：確認 ＋9.9万円、最新6か月 −1.6万円
3. **最近ほど重く数える**方法は、ルールによって良くなったり悪くなったりで、決まった傾向はなかった
4. **毎月「直近で一番調子が良いルール」に乗り換える**方法は、どの組み合わせでも最新6か月がマイナス（−0.6万〜−5.2万円）。調子の良いものを追いかけると、ちょうど調子が落ちるところで乗ることが多い

## まとめ

- 「今を重く見る」は、**直近3か月くらい**がちょうど良い。それより短いと、ぶれに振り回される
- 一番安定していたのは「一目均衡表＋損切り幅の下限＋日足の流れ（直近3か月で毎月見直し）」
- ただし、7通りの方法×12のルールを試した中での一番なので、良く見えすぎている可能性がある。本当の確認は、これからの値動きで仮想取引をして行う
