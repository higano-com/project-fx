# レンジ（10ドルくらいの幅）を取りに行く売買の検証（2026年11月5日）

> 過去の成績は、将来の成績を約束するものではありません。1回2,500円で計算。

## 1. 1時間足で見たレンジ

- 直近6時間の値幅が10ドル以内の時間：2021〜2023年は約半分、2025年は7％、**2026年は1％**
- レンジの下で買い・上で売る売買（毎月見直し）：**−19.2万円**（591回、利益÷損失0.80）。幅をドルで決めても −4.6万円

## 2. 3分足・5分足で見たレンジ（1分足 15万本、2026年7月24日〜11月5日）

- 30分間の値幅が10ドル以内のことは多い（69％、平均7.8ドル）。60分間なら48％
- 直前4週間で調整し、次の1週間で確かめることをくり返した結果：

| | スプレッド0.8ドル（今のGMO） | スプレッド0.4ドル（仮に半分なら） |
|---|---|---|
| 3分足 | 44回・勝率23％・**−4.4万円** | 88回・勝率26％・−4.2万円 |
| 5分足 | 68回・勝率22％・**−7.4万円** | 176回・勝率33％・−0.5万円 |

## 分かったこと

1. 10ドルの幅で取りに行くと、**スプレッド0.8ドルが幅の約1割**を占める。往復でさらに損切りのずれもかかるので、コストに勝てない
2. 短い時間のレンジは「あと少しで反対側」というところで抜けてしまうことが多く、勝率が低い（22〜33％）
3. スプレッドが半分でもトントン以下。**今のGMOのコストでは、10ドル幅のレンジ売買は採用しない**
4. 1分足のデータは約3か月半しかない。データが増えたら、もう一度確かめる
