# 本物の価格につなぐ手順（Twelve Data ＋ Cloudflare）

所要時間：30分ほど。費用：0円。iPhone の Safari でもできますが、画面が広いパソコンやiPadのほうが楽です。

> Cloudflare の画面の名前は時々変わります。ここに書いた名前と少し違っても、近い名前のボタンを探してください。困ったら、画面に出ている文字をそのまま教えてください。

## 全体の流れ

```
iPhone のアプリ（Cloudflare Pages に置く）
   ↓ 「金の価格ちょうだい」
価格の中継役（functions/api/series.js。APIキーはここにだけ置く）
   ↓
Twelve Data（価格データの会社）
```

---

## ステップ1：Twelve Data のAPIキーを用意する

1. Safari で `twelvedata.com` を開き、右上の「Sign up」から無料登録する（無料プランのまま。カード情報は不要）
2. ログイン後、「API Keys」を開き、表示される長い英数字（APIキー）を確認する
3. 試しに、Safari のアドレス欄に次を入れて開く（`あなたのキー` を置き換える）

   ```
   https://api.twelvedata.com/price?symbol=XAU/USD&apikey=あなたのキー
   ```

   `{"price":"…"}` と数字が出れば成功。`XAG/USD`（銀）と `USD/JPY`（ドル円）も同じように試す

**APIキーは、チャットやメールに貼らないでください。** 入れる場所はステップ3だけです。

## ステップ2：Cloudflare にアプリを置く

1. `dash.cloudflare.com` を開き、無料アカウントを作る（メールアドレスとパスワード）
2. 「アプリを作成」を押し、画面のいちばん下の「レガシーのPagesワークフロー…**ページへ進む**」を押す →「Import an existing Git repository」の「Get started」を選ぶ（上に並ぶ「GitHubに接続」などは Workers 用なので使いません）
3. 「GitHub に接続」を押し、GitHub にログインして Cloudflare に許可を出す
   - どのリポジトリを許可するか聞かれたら、`project-fx` だけを選ぶ
4. 一覧から `higano-com/project-fx` を選んで「セットアップを開始」
5. 次のように入力する

   | 項目 | 入れる内容 |
   |---|---|
   | プロジェクト名 | 好きな名前（英小文字。例：`kingin-kensho`）。これがURLになります |
   | 本番ブランチ | `claude/connection-check-m84res` |
   | フレームワーク プリセット | なし（None） |
   | ビルドコマンド | `sh scripts/build.sh` |
   | ビルド出力ディレクトリ | `dist` |

6. 「保存してデプロイ」を押す。1〜2分で完了し、`https://（プロジェクト名）.pages.dev` というURLが表示される

この時点で開くと、「本物の価格を読み込めませんでした。APIキーがまだ設定されていません」と出ます。これで正常です。

## ステップ3：APIキーを秘密の設定に入れる

1. 作ったプロジェクトを開き、「設定」→「変数とシークレット」（または「環境変数」）を開く
2. 「追加」を押し、次のように入れる
   - 種類：**シークレット**（「暗号化」と書かれていることもあります）
   - 変数名：`TWELVEDATA_API_KEY`（コピーして貼り付けると間違えません）
   - 値：ステップ1のAPIキー
3. 保存する
4. 「Deployments」の一覧に戻り、いちばん上のデプロイを**タップして詳しい画面を開き**、右上の「Manage deployment」または「…」から「Retry deployment」（再デプロイ）を押す。設定は再デプロイ後に効きます
   - iPhone の縦向きでは、一覧の「…」が画面の右に隠れて見えません。行をタップして詳しい画面から操作してください
   - GitHub に新しい更新が届いたときも、自動で再デプロイされます

> 種類は必ず「シークレット（Secret）」を選んでください。「テキスト（Text）」でも動きますが、Cloudflare の画面にキーがそのまま表示されてしまいます。

## ステップ4：iPhone で開く

1. Safari で `https://（プロジェクト名）.pages.dev` を開く
2. 右上の表示が緑の「本物の価格」になっていれば完了
3. 共有ボタン →「ホーム画面に追加」で、アプリのように開けます（次の段階の通知にも必要です）

## ステップ5（おすすめ）：自分だけが開けるようにする

Twelve Data の無料プランは「個人で使う」ための条件です。URLを知っている人が誰でも開ける状態は避けたほうが安心です。

1. Cloudflare の左メニューで「Zero Trust」を開く（初回はチームの名前と、無料プラン「Free」を選ぶ。支払い方法の登録を求められることがありますが、無料プランなら請求はありません）
2. 「Access」→「アプリケーション」→「アプリケーションを追加」→「セルフホスト」
3. ドメインに `（プロジェクト名）.pages.dev` を入れる
4. ポリシーで「許可（Allow）」を選び、条件を「メールアドレス」＝ あなたのメールアドレス にする
5. 保存する

これで、開くときにメールに届く数字（ワンタイムコード）を入れた人だけが見られるようになります。

## うまくいかないとき

| 画面の表示 | よくある原因 |
|---|---|
| APIキーがまだ設定されていません | ステップ3の後に再デプロイしていない／変数名の打ち間違い |
| APIキーが正しくないようです | キーのコピーが途中で切れている／Twelve Data でキーを作り直した後、古いキーのまま（作り直したら Cloudflare の値も入れ直して再デプロイ） |
| 「識別番号」が前と同じまま | キーの保存ができていない。Cloudflare で値を入れ直して「Save」を押し、再デプロイする（識別番号はキーから作った8文字で、キーそのものは分かりません） |
| 無料枠の回数を使い切りました | 1日800回の上限。翌日に戻ります（ふだんの使い方なら届きません） |
| ページが開かない／真っ白 | ビルドコマンドと出力ディレクトリの入力ミス |
