# くり返しの検証（2026年11月5日）

> 過去の成績は、将来の成績を約束するものではありません。

対象：今のアプリのルール（一目均衡表＋損切り幅の下限＋日足の流れ、毎月・直近3か月で見直し）。2021年3月〜2026年11月、1回2,500円で計算。

## 1. コストが増えたとき

| スプレッド・ずれ | 損益 | 回数 | 利益÷損失 |

| 0.8・0.1（今のGMO） | ＋14.6万円 | 323回 | 1.28 |
| 1.2・0.1 | ＋7.7万円 | 220回 | 1.22 |
| 1.6・0.1（2倍） | ＋6.3万円 | 144回 | 1.27 |

→ コストが2倍でもプラス。

## 2. 見直しの日がずれたとき（弱点が見つかった）

| 見直しの日 | 今のやり方 | 改善案（4回分の平均で選ぶ） |
|---|---|---|
| ずらさない | ＋14.6万円 | ＋9.4万円 |
| 7日ずらす | ＋5.8万円 | ＋7.7万円 |
| 14日ずらす | ＋4.1万円 | ＋10.5万円 |
| 21日ずらす | ＋5.9万円 | ＋5.1万円 |
| 平均・ばらつき | 7.6万円・4.1万円 | **8.2万円・2.0万円** |
| 最新6か月 | ＋0.4〜＋4.4万円 | **＋1.9〜＋3.4万円** |

→ 今のやり方の＋14.6万円は「見直しの日がたまたま良かった」分を含む。**改善案（1週間ずつずらした4回分の直近3か月の点の平均で選ぶ）をアプリに採用**。ばらつきが半分になった。
