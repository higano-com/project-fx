# project-fx: ボートレースAI

番組表から各艇の **1着確率** を LightGBM で推定し、Harville モデルで **3連単120通りの確率** に展開する予測AIです。
バックテストで的中率・回収率まで確認できます。

## 仕組み

```
公式データ(LZH) ─ download ─▶ b*.txt (番組表) / k*.txt (競走成績)
                                   │ parse.py
                                   ▼
                 features.py: 基本情報 + レース内相対値 + 過去成績(リークなし)
                                   │
                 model.py: LightGBM(1着か否か) → レース内正規化 → Harville で3連単確率
                                   │
                 backtest.py: 時系列で分けたテスト期間の的中率・回収率
```

| 特徴量 | 内容 |
|---|---|
| 基本 | 枠番, 場, 級別, 年齢, 体重, 全国/当地 勝率・2連率, モーター/ボート 2連率 |
| 相対 | 上記主要項目の「レース平均との差」と「レース内順位」 |
| 履歴 | 対象日**より前**の成績から: 出走数, 1着率, 3着内率, 平均着順, 平均ST, 枠別1着率/3着内率 |

## 使い方

```bash
pip install -e ".[dev]"

# 1) 公式データ取得 (www1.mbrace.or.jp から番組表・成績のLZHを取得して展開)
boatrace-ai download --start 2023-01-01 --end 2024-12-31 --out data/raw

# 2) 学習 + バックテスト (既定: 末尾20%の期間をテスト)
boatrace-ai train --data data/raw --model models/model.pkl --test-from 2024-10-01

# 3) 予測 (当日の番組表 + 過去成績)
boatrace-ai predict --program data/raw/b241225.txt --data data/raw --venue 12
```

ネットワークなしで試すなら合成データ(本物と同じ書式)で一通り動きます:

```bash
boatrace-ai synth --out data/synth --days 150
boatrace-ai train --data data/synth --model models/synth.pkl
```

## 注意点

- **パーサは実データで未検証です。** 開発環境から mbrace.or.jp に接続できなかったため、
  公開されている書式に合わせて書き、合成データとテスト用の手書きサンプルでのみ確認しています。
  実データで初回に `load_dir()` の件数(1日あたり 場数×12R×6艇)を確認してください。
- 過去データには締切オッズが無く、確定した的中組の払戻しかないため、
  バックテストは「確率上位N点買い」「本命確率がしきい値以上のレースのみ」の戦略評価です。
  控除率25%があるので、的中率が高くても回収率100%超えは簡単ではありません。
- 合成データでの成績は合成モデルの性質を反映するだけで、実際の予測精度の目安にはなりません。

## 今後の改善案

- 直前情報(展示タイム・展示ST・チルト・進入)を取得して特徴量に追加
- 締切前オッズを取得して期待値(確率×オッズ)ベースの買い目選択
- LambdaRank / 着順全体を使う学習、確率のキャリブレーション
- 天候・風・波、選手の当地/コース別の詳細成績
