# project-fx

金スポット・銀スポット（ドル建て）の売買判断を**検証するため**の、iPhone で使える Web アプリです。

- 実際の注文はできません。GMOクリック証券の口座にも接続しません。
- GMOクリック証券の画面からデータを自動で取ることはしません。
- 表示する判断や検証結果は、将来の利益を約束するものではありません。

## いまの状態

- 価格データは **Twelve Data（無料プラン）** に決定 → 候補の比較は [docs/data-sources.md](docs/data-sources.md)
- Cloudflare に置いて APIキーを設定すると本物の価格で動きます → 手順は [docs/setup-cloudflare.md](docs/setup-cloudflare.md)
- 設定前や、読み込みに失敗したときは、**サンプルデータ（架空の値動き）** で動き、画面にそう表示します

## 画面

| タブ | できること |
|---|---|
| 判断 | 金・銀のチャートと価格、買い／売り／見送りの判断と理由、エントリー・利確・損切りの候補価格、仮想取引の記録 |
| 仮想取引 | 口座の状態（本日の損失・落ち込みの上限までの残り）、保有中・決済済みの取引 |
| 成績 | 資金推移グラフ、勝率・損益・取引コストなどの集計 |
| 過去検証 | 調整期間（前7割）で設定を選び、確認期間（後ろ3割）で試す。過去に合わせ込みすぎていないかを確認 |
| 設定 | 資金管理のルール、取引コスト、判断ルールの数字、やり直し |

## 仮想取引の初期設定

- 資金 100万円 / 1回の許容損失 2,500円 / 1日の損失上限 10,000円
- 資金が最高値から5％減ったら停止 / 同時保有は最大2つ（同じ銘柄は1つまで）
- スプレッド・損切り時の価格のずれ・持ち越し費用を損益から差し引き

## ファイル

- `app/index.html` … アプリ本体（1ファイル。記録はその端末のブラウザ内に保存）
- `functions/api/series.js` … 価格の中継役（Twelve Data から価格を読むだけ。APIキーは Cloudflare の秘密の設定に置く）
- `scripts/build.sh` … Cloudflare Pages 用に `dist/` を作る
- `docs/data-sources.md` … 価格データの候補と、次の段階（24時間監視・通知）の費用
