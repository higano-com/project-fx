# やることリスト（検証と判断の改善）

方針：**足すものは1つずつ、確認期間で効果が出たものだけ採用する。**
材料を増やすほど「過去にだけ合う」設定が作りやすくなるため、毎回、調整期間と確認期間を分けて確かめる。

## 段階A：土台を正しくする（最優先）

- [ ] 本物の過去データを取得する（GitHub Actions → `data/`）
- [ ] データの異常（飛んだ値・欠け・週末の扱い）を見つけて直す
- [ ] 過去検証の計算を見直す（1回の損失が許容額を大きく超える取引がないか）

## 段階B：相場のパターン別に検証する

- [ ] 暴落／暴落後の暴騰／強い上昇／強い下落／横ばい／荒れた相場 を自動で見分け、パターンごとの成績を出す
- [ ] コストが増えたとき（スプレッド2倍など）、取引の順番を入れ替えたときにも崩れないか
- [ ] 期間をずらしながら何度も「調整→確認」を繰り返す検証（ウォークフォワード）

## 段階C：判断のルールを増やして比べる

- [ ] 今のルール（上向きの流れ中の押し目買い）
- [ ] 高値・安値を抜けたら乗る（ブレイクアウト）
- [ ] 急落・急騰しすぎたら戻りを狙う（逆張り）
- [ ] 長い足（4時間・日足）の流れと合わせる
- [ ] その他の指標（MACD、ボリンジャーバンドなど）

## 段階D：経済指標の発表を考える

金は米国の経済指標で大きく動く。

- [ ] 主な発表の日時を用意する（米雇用統計、CPI（物価）、FOMC（米国の金利の決定）、PCE、GDP など）
- [ ] 発表の前後○時間は新しい取引を見送るルールを試す
- [ ] 発表直後の大きな動きに乗る／見送るのどちらが良いかを比べる
- 日時の出どころ：米労働統計局・FRB などの公式の予定表（無料）

## 段階E：情勢（関連する市場の動き）を考える

ニュースそのものは過去検証が難しいため、数字で表せるものから試す。

- [ ] 米国の金利（10年国債利回り・実質金利）、ドルの強さ（ドル指数）
- [ ] 市場の不安の大きさ（VIX）
- [ ] 地政学的な出来事の影響は「値動きが急に荒れた」ことで見分ける（段階Bの「荒れた相場」）
- 日時の出どころ：FRED（米セントルイス連銀の無料データ）など。利用条件を確認してから使う

## 段階F：24時間監視とiPhone通知、銀の記録

- [ ] Cloudflare で15分ごとに判断し、条件がそろったら iPhone に通知（Web プッシュ）
- [ ] 銀の「今の価格」を1時間ごとに記録して値動きをためる
- [ ] 経済指標の発表前にお知らせ
