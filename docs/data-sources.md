## おすすめ

**A（Twelve Data 無料プラン）＋ D（Dukascopy の過去データ）で、0円から始める**

- 画面の価格と判断：Twelve Data。1時間足を使うので、15分おきに金・銀・ドル円の3つを取れば1日288回で、無料枠（800回）に収まります。
- 過去検証：Dukascopy から1時間足のCSVを数年分ダウンロードしてアプリに読み込みます（読み込み機能はデータ確定後に作ります）。
- 無料枠で足りなくなったら、Twelve Data の有料プランに上げるか、B に切り替えます。

## 共通の注意

- どの提供元の価格も、GMOクリック証券の「金スポット」「銀スポット」の価格とは少しずれます（各社が独自に価格を出しているため）。判断と候補価格は目安として使い、実際の発注価格はGMOの画面で確認してください。
- GMOクリック証券の画面から自動でデータを取ることはしません。
- 今の閲覧用ページ（claude.ai のアーティファクト）は、安全のため外部サイトに接続できません。本物のデータにつなぐ段階で、アプリを自分用の公開場所（下の「次の段階」参照）に移します。

# 次の段階：24時間監視とiPhone通知（説明のみ・まだ作りません）

iPhoneの画面を閉じている間も判断を続けるには、**常に動いている小さなサーバー**が必要です。

| 方法 | 月額の目安 | 内容 | 手間 |
|---|---|---|---|
| **1. Cloudflare（無料プラン）**（おすすめ） | 0円 | Workers が15分おきに価格を取って判断し、条件がそろったら通知。アプリ本体は Cloudflare Pages に置く | アカウント作成のみ。サーバーの管理は不要 |
| 2. 小さな VPS（さくらのVPS、ConoHa など） | 月500〜1,000円程度 | 自分専用のサーバーを24時間動かす | OSの更新など管理が必要 |

通知の方法：

- **Web プッシュ（0円）**：Safari でアプリを「ホーム画面に追加」すると、iPhone（iOS 16.4以降）でも通知を受け取れます。
- 予備案：通知専用アプリ（ntfy は無料、Pushover は1端末あたり買い切り5ドル程度）。
- LINE Notify は 2025年3月に終了したため使いません。

費用の合計の目安：**月0円**（Cloudflare 無料 ＋ Twelve Data 無料 ＋ Web プッシュ）。
独自のドメイン名を付けたい場合だけ、年1,500円前後かかります（なくても動きます）。
