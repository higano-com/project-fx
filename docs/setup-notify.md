# 通知の準備（24時間の見張り役）

ほかのアプリは要りません。ホーム画面に追加した「金銀シグナル検証」に通知が届きます。費用は0円（クラウドフレアの無料の範囲）。

## しくみ

- 見張り役（`worker/`）が毎時3分に金の判断をする（アプリと同じ計算。1,300本の足で一致を確認済み）
- 「買い」「売り」が出たら、登録したiPhoneに通知を送り、アイコンの右上に数字を付ける
- 登録などの記録は、見張り役専用の保管場所に置く
- 価格を読むだけ。注文や口座への接続はしない

## 手順

1. クラウドフレアで「アプリを作成」→「GitHubに接続」→ `project-fx` を選ぶ
2. 設定
   - 名前：`kingin-mihari`
   - ブランチ：`claude/connection-check-m84res`
   - ルートディレクトリ（詳細設定の中）：`worker`
   - 「デプロイ」を押す
3. できたワーカーの「設定」→「変数とシークレット」で、シークレット `TWELVEDATA_API_KEY` を追加（アプリと同じキー）
4. ワーカーのアドレス（`https://kingin-mihari.〇〇.workers.dev`）を伝える → アプリに組み込む
5. ホーム画面のアプリの「設定」→「通知を受け取る」を押して、許可する
6. 「テストの通知を送る」で届くか確かめる

## つまずきやすいところ

- 1回目のデプロイは、ブランチが `main` のままだと失敗する。ワーカーの「設定」→「ビルド」の「本番ブランチ」（翻訳表示では「生産部門」）を `claude/connection-check-m84res` に変えて保存し、もう一度デプロイする
- ルートディレクトリ（パス）は `/worker`（翻訳表示では「/ワーカー」）
- キーは作成画面の「変数名・変数の値」で入れて「暗号化」を押せば、あとで入れ直さなくてよい

## 確かめ方

- `https://kingin-mihari.〇〇.workers.dev/status`：最後に判断した時刻、最後の通知、登録数
